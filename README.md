# OsintX

Official link hub and documentation pointers for **[OsintX.IO](https://osintx.io)** — a web platform for **authorized** open-source intelligence (OSINT) and security research workflows.

This repository does **not** distribute leaked data, malware, or exploit code. It only describes the public product and how to use it lawfully.

## What is OsintX?

OsintX is a hosted OSINT workspace for analysts, moderators, and security professionals who need structured lookups and exportable results—not scattered manual searches.

Typical **legitimate** use cases:

- Fraud and abuse investigations with proper authorization  
- Account-trust and identity research for platform safety teams  
- Correlating public and licensed intelligence sources in one case file  
- Learning OSINT methodology via guides on the [blog](https://osintx.io/blog)

Features are delivered through the web app (search modules, history, JSON export, optional Enterprise API). Details and pricing are on the site.

## API

Enterprise customers can use the documented REST API (authentication via API keys). Start with the health endpoint:

```bash
curl -sS "https://osintx.io/api/v1/ping"
```

Full reference: [https://osintx.io/docs?tab=api](https://osintx.io/docs?tab=api)

## Acceptable use

Use OsintX only where you have **legal authority** and a **valid purpose** (e.g. your organization’s security program, contracted investigation, or personal accounts you own).

**Do not** use OsintX or this repository to harass, stalk, dox, or target individuals; to bypass access controls; or to violate GitHub’s [Terms of Service](https://docs.github.com/site-policy/github-terms/github-terms-of-service) or applicable law.

Report abuse: contact addresses listed on [osintx.io/legal](https://osintx.io/legal).
